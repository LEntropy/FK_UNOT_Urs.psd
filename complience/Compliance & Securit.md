## 📌 1. 개요 (Overview)
본 문서는 DONTAI 플랫폼의 법적 신뢰성 및 데이터 보호 통제를 위해 작성된 **Compliance & Security 명세서**입니다.  
AI 기반 무단 크롤링/학습 방지를 위한 **법적 약관 정의**, **증거 패키지(Evidence Pack) 자동 생성 파이프라인**, **감사 로그(Audit Log) DB 스펙**, 그리고 **DevSecOps 보안 정책**을 포함합니다.

## 📜 2. 이용약관 및 법적 면책 방패막 (ToS & Disclaimer)

### 2.1 AI 무단 학습 금지 조항 (Do-Not-Train Policy)
> **[제 X 조: 창작물의 보호 및 AI 학습 금지]**
> 1. 본 플랫폼(DONTAI)에 게시된 모든 디지털 창작물의 저작권은 원작자에게 있습니다.
> 2. 이용자 및 제3자는 본 플랫폼의 사전 서면 승인 없이 어떠한 경우에도 게시된 창작물을 AI/ML(인공지능 및 머신러닝) 모델의 학습, 데이터셋 구축, 화풍(LoRA 등) 복제 목적으로 수집, 크롤링, 가공할 수 없습니다.
> 3. 본 조항을 위반하여 무단 학습 및 무단 도용을 진행할 경우, 플랫폼은 온체인 타임스탬프 및 KMS 기반 증거 패키지(Evidence Pack)를 발급하여 민·형사상 법적 조치 및 침해 중지 청구를 지원합니다.

### 2.2 서비스 이용 한계 및 법적 면책 조항 (Disclaimer)
> **[제 Y 조: 기술적 보호조치 및 서비스 면책]**
> 1. 플랫폼이 제공하는 AI 학습 방지 기능(L1~L3 보호강도)은 기술적 억제 수단이며, 악의적인 이미지 복원 기술에 의한 100% 학습 차단을 보증하지 않습니다.
> 2. 높은 보호강도(L3) 적용 시 노이즈 삽입으로 인한 원본 대비 해상도 및 화질 저하가 발생할 수 있으며, 이는 AI 학습 차단을 위한 의도적 가공으로 플랫폼은 이에 대한 손해배상 책임을 지지 않습니다.
> 3. 플랫폼이 자동으로 발급하는 '증거 패키지(Evidence Pack)'는 기술적·정황적 무결성을 증명하는 자료이며, 플랫폼이 직접적인 법적 대리인으로서 소송을 대행하거나 판결 결과를 보장하지 않습니다.

## 🛠️ 3. 증거 패키지 자동 생성 엔진 (`EvidenceGenerator.js`)

Node.js 환경에서 AI(도용 탐지) + BE(타임스탬프/해시) + KMS(전자서명) 데이터를 결합하여 **PDF 형태의 증거 리포트**를 발급하는 핵심 모듈입니다.

```javascript
/**
 * @file EvidenceGenerator.js
 * @description DONTAI Compliance Part - Automated Infringement Evidence Pack Generator
 * @author Compliance Lead
 */

const PDFDocument = require('pdfkit');
const fs = require('fs');

/**
 * 침해 증거 리포트(PDF) 자동 생성 함수
 */
async function generateEvidencePack(payload, outputPath) {
  return new Promise((resolve, reject) => {
    const doc = new PDFDocument({ size: 'A4', margin: 40 });
    const writeStream = fs.createWriteStream(outputPath);

    doc.pipe(writeStream);

    try {
      // [HEADER]
      doc.rect(40, 40, 515, 50).fill('#1A365D');
      doc.fillColor('#FFFFFF').fontSize(18).font('Helvetica-Bold').text('DONTAI DIGITAL ASSET EVIDENCE PACK', 55, 58);
      doc.fontSize(9).font('Helvetica').text('CERTIFIED INFRINGEMENT EVIDENCE REPORT', 55, 78);
      doc.moveDown(3);

      // [SECTION 1] 원본 자산 및 보호 등급
      renderSectionTitle(doc, '1. Original Asset & Protection Profile');
      renderKeyValueTable(doc, [
        ['Asset ID', payload.asset.id],
        ['Title', payload.asset.title],
        ['Creator Wallet', payload.asset.creatorWallet],
        ['Original SHA-256', payload.asset.originalHash],
        ['Protection Level', `Level ${payload.asset.protectionLevel} (Score: ${payload.asset.protectionScore}/100)`],
        ['On-Chain Tx Hash', payload.asset.txHash],
        ['Block Timestamp', payload.asset.blockTimestamp]
      ]);
      doc.moveDown(1.5);

      // [SECTION 2] 무단 도용 탐지 정황
      renderSectionTitle(doc, '2. Unauthorized Infringement Detection');
      renderKeyValueTable(doc, [
        ['Target Violation URL', payload.detection.targetUrl],
        ['Similarity Score', `${payload.detection.similarityScore}% (High Confidence)`],
        ['Watermark Detection', payload.detection.watermarkFound ? 'CONFIRMED' : 'NOT DETECTED'],
        ['Detected Timestamp', payload.detection.detectedAt]
      ]);
      doc.moveDown(1.5);

      // [SECTION 3] KMS 전자서명
      renderSectionTitle(doc, '3. Cryptographic Integrity & KMS Signature');
      doc.fontSize(8).font('Courier-Bold').fillColor('#2B6CB0').text('[ Platform KMS Digital Signature (ECDSA-SHA256) ]');
      doc.font('Courier').fillColor('#4A5568').text(payload.kms.signature, { width: 515 }).moveDown(1);

      // [FOOTER]
      doc.moveTo(40, doc.y).lineTo(555, doc.y).strokeColor('#CBD5E0').stroke().moveDown(1);
      doc.fontSize(7).font('Helvetica').fillColor('#A0AEC0').text(
        'LEGAL NOTICE: This Evidence Pack is automatically generated by the DONTAI Compliance Protocol. ' +
        'It contains immutable cryptographic proofs confirming asset ownership and technical infringement detection.',
        { align: 'justify' }
      );

      doc.end();
      writeStream.on('finish', () => resolve(outputPath));
      writeStream.on('error', (err) => reject(err));
    } catch (err) {
      reject(err);
    }
  });
}

function renderSectionTitle(doc, title) {
  doc.fontSize(12).font('Helvetica-Bold').fillColor('#2D3748').text(title).moveDown(0.5);
}

function renderKeyValueTable(doc, rows) {
  doc.fontSize(9).font('Helvetica');
  rows.forEach(([key, val]) => {
    doc.fillColor('#718096').text(`${key}: `, { continued: true }).fillColor('#1A202C').font('Helvetica-Bold').text(val).font('Helvetica');
  });
}

module.exports = { generateEvidencePack };
